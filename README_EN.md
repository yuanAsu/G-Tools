# Complex Excel Parser

A production-grade Python application designed to parse complex, non-standard, or even **corrupted** Excel files. It integrates Global Gene Repair technology, Qwen LLM semantic extraction, and multiple structured parsing modes.

## Core Features

### 1. Global Gene Repair
To handle Strict OOXML files generated by WPS or files with broken external links, this system includes a powerful pre-processing cleaner (`src/loader.py` & `src/preprocessor.py`) ensuring 100% readability:
- **Physical Removal**: Automatically strips crash-inducing files like `calcChain.xml`, `externalLinks`, `printerSettings`, and `vbaProject.bin`.
- **Namespace Transplant**: Globally replaces Strict OOXML namespaces with Microsoft Standard Transitional OOXML.
- **Surgical Repair**: Uses regex to precisely remove problematic `<definedNames>` and `<externalReferences>` nodes from `workbook.xml`.
- **Smart Fallback**: Prioritizes full loading, automatically switching to `read_only=True` mode if that fails.

### 2. Multi-Mode Parsing
- **Standard Table**: Automatically handles merged cells and flattens multi-level headers.
- **Semantic Anchoring (`parse_table_at_anchor`)**: Locates specific sub-tables in mixed sheets via keywords.
- **Form Mode (`parse_form`)**: Smartly extracts unstructured "Key: Value" pairs.
- **Hierarchy Mode (`parse_hierarchy`)**: Builds nested JSON trees from financial statements based on indentation.

### 3. LLM Semantic Extraction (Qwen Integration)
- **Context Serializer (`src/serializer.py`)**: Converts Excel data into Token-optimized Markdown, automatically truncating long text and filtering empty rows.
- **Prompt Engineering (`src/llm_bridge.py`)**: Built-in prompt templates for Real Estate/Finance domains, ready for Qwen/GPT structured data extraction.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Generate sample data:
   ```bash
   python scripts/generate_sample_excel.py  # Basic V1 data
   python scripts/generate_v2_data.py       # Advanced V2 data (Anchors, Forms, Hierarchy)
   ```

## Usage

### Basic Parsing
```python
from src.parser import ExcelParser
import json

# Automatically triggers "Global Gene Repair"
parser = ExcelParser("data/complex_v2.xlsx")

# 1. Semantic Anchor
df_funding = parser.parse_table_at_anchor("Mixed Data", "Funding Assumptions")

# 2. Form Extraction
project_info = parser.parse_form("Project Form")

# 3. Hierarchy Extraction
financials = parser.parse_hierarchy("Financial Statement")
print(json.dumps(financials, indent=2, ensure_ascii=False))
```
